## Verdicts

* **usable**: a tagged declaration states what the paper uses, in the generality the paper
  uses it (algebraic spaces, or schemes where the paper applies the tag to schemes, or a
  categorical/topological statement).
* **usable†**: the tagged declaration does **not** apply to algebraic spaces as stated (see
  "Universes" below), but an **untagged** AxiomMath declaration, named in the table and
  whose signature was read, states the paper's use for spaces.  Using it is a use of
  AxiomMath without a tag to cite; ASSUMPTIONS rows should name the declaration.
* **partial**: only part of what the paper uses, a special case, or a site-level statement
  with no space-level counterpart located.
* **schemes only**: the declarations are for schemes (or rings) and the paper needs the
  algebraic-space version.
* **absent**: nothing in AxiomMath.

## Three things to know before using the table

**Universes (the source of every `usable†` and most `partial`).**  AxiomMath's ringed
sites and topoi are `RingedSite.{u,v,w}` / `RingedTopos.{v,u,w}` (objects in `Type u`,
morphisms in `v`, ring values in `w`).  The small étale site of an algebraic space is
`AlgebraicGeometry.smallEtaleRingedSite : RingedSite.{u+1, u, u}` and its topos
`Space.smallEtaleRingedTopos : RingedTopos.{u, u+1, u}`.  Universe levels are not
cumulative, so a site-level result stated at `RingedSite.{u,u,u}`, `RingedTopos.{u,u,u}`
or `RingedSite.{0,0,0}` (or with modules `SheafOfModules.{0}`) **cannot be instantiated**
at a space.  This affects 07A4, 07A5, 08FU, 08G8, 08H4, 08H6, 08J7–08JJ, 09J9, 0A97,
0B6C, 0D6G, 0FPK–0FPN, 0H9A.  The `…OfToposHom` declarations with free universes (06YY,
07A6, 07A7, 0D6D, 0D6E, 0E46, 0E47, 0G7E) and the universe-general ones (08FV `_general`,
08G5) do apply.  AxiomMath carries untagged space-level versions of several of the
affected statements (column "Also"); for the rest none was located.

## How to regenerate

```bash
git clone -q --depth 1 --filter=blob:none https://github.com/AxiomMath/Stacks /tmp/axs
git -C /tmp/axs checkout -q f56a316ddf7a930906d88b78d6f9a2668cffd0cf
OUT=$(mktemp -d)
python3 -I scripts/axiommath/tag_map.py /tmp/axs "$OUT"          # about 3-5 minutes
python3 -I scripts/axiommath/render_tags.py "$OUT" > results/AXIOMMATH_TAGS.md
# section tags (needs the Stacks Project tags file and chapter sources in $SP):
ALL=1 python3 -I scripts/axiommath/tag_map.py /tmp/axs "$OUT/all"
python3 -I scripts/axiommath/section_tags.py "$SP" "$OUT/all/axiommath_tags.tsv" 003S 0118 …
```

`TEXONLY=1 python3 -I scripts/axiommath/tag_map.py /tmp/axs` prints only the TeX side
(seconds).  The renderer refuses to run if `judgments.txt` and the extracted tag set
disagree, so a new manuscript forces the judgments to be updated.
